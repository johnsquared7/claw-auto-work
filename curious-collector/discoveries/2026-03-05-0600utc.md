## 🔥 Polars — The Fast DataFrame Library

**URL:** https://pola.rs/

A DataFrame library written in Rust with Python bindings. Benchmarks show it's significantly faster than pandas for large datasets — often 5-10x quicker for common operations. 

**Why it matters for NHS workflow:**
- Handles larger datasets without memory issues
- Lazy evaluation for optimized query plans
- Compatible API with pandas for easier migration
- Great for report automation pipelines

**Verdict:** Worth trying for any Python data work beyond simple analysis.

## 📊 ydata-profiling — Auto-EDA Reports

**URL:** https://github.com/ydataai/ydata-profiling (formerly pandas-profiling)

Generates comprehensive HTML reports from any DataFrame with:
- Statistical summaries
- Correlation matrices  
- Missing value analysis
- Distribution visualizations

**Why it matters:**
- Seconds to get full EDA instead of hours
- Perfect for quickly understanding new NHS datasets
- Export to HTML/PDF for stakeholder sharing

```python
from ydata_profiling import ProfileReport
profile = ProfileReport(df, title="NHS Dataset Report")
profile.to_file("report.html")
```

## 🖥️ Power BI Alternatives Worth Exploring

**URL:** https://www.metabase.com/

- Simple query builder
- Embeddable dashboards

**URL:** https://looker.com/
