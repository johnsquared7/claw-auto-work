## 🏥 Pandera - Data Validation for Pandas DataFrames

**What:** Statistical data validation library with type-hinting for pandas  
**Why it's interesting:** Transform ad-hoc validation into clear, maintainable schemas. Catches data quality issues early in pipelines - critical for healthcare data.  
**Use case for NHS:** Validate patient data extracts against expected schemas, check NHS numbers are valid, ensure date ranges are sensible  
**URL:** https://pandera.readthedocs.io/  
**Install:** `pip install pandera`

```python
import pandera as pa
from pandera import Column, Check

schema = pa.DataFrameSchema({
    "nhs_number": Column(str, Check.str_length(equals=10)),
    "age": Column(int, Check.greater_than(0)),
    "admission_date": Column(pa.DateTime, Check.less_than("2026-01-01"))
})
validated_df = schema.validate(df)
```

## 💾 Vaex - Billions of Rows on a Laptop

**What:** High-performance lazy out-of-core DataFrame library  
**Why it's interesting:** Memory-mapped files mean you can work with datasets larger than RAM without loading everything into memory. 10x faster aggregations than pandas on large datasets.  
**Use case for NHS:** Processing full years of hospital activity data (HES/ECD) without memory issues  
**URL:** https://vaex.io/  
**Install:** `pip install vaex`

```python
import vaex
df = vaex.open('/path/to/large/file.hdf5')  # Doesn't load into RAM
df.summary()  # Instant on 100GB+ files
df.groupby('provider').agg({'waiting_list': 'mean'})
```

## 📊 ITables - Interactive Jupyter Tables

**What:** DataTables for Jupyter notebooks  
**Why it's interesting:** Search, sort, paginate DataFrames directly in notebooks. Only renders visible rows = fast on large DataFrames.  
**Use case for NHS:** Browse large patient lists in notebooks without printing thousands of rows  
**URL:** https://pypi.org/project/itables/  
**Install:** `pip install itables`

```python

```

**Use case for NHS:** Very large dataset processing if you have GPU hardware available
