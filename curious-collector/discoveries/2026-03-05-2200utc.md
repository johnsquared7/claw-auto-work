## 🔗 Splink - Probabilistic Record Linkage for Healthcare

**What:** Python package for deduplicating and linking records without unique identifiers  
**Why it's genuinely interesting:** Used by NHS England, ONS, and UK public sector for production data linkage. Links 1M records in ~1 minute on a laptop. Unsupervised learning - no training data required.

**Use case for NHS:** 
- Link patient records across different systems (PDS, HES, etc.)
- Deduplicate patient lists with spelling variations
- Match NHS numbers where identifiers are missing/partial

**URL:** https://moj-analytical-services.github.io/splink/  
**GitHub:** https://github.com/moj-analytical-services/splink  
**Install:** `pip install splink`

```python
import splink
from splink.duckdb.linker import DuckDBLinker

# Link records probabilistically
linker = DuckDBLinker(df, settings)
predictions = linker.predict()
clusters = linker.cluster_pairwise_predictions_at_threshold(predictions)
```

**Wow factor:** NHS England is building their new probabilistic linkage service on Splink - direct relevance to John's work.

## 📊 DuckDB vs Polars vs Pandas - March 2026 Benchmarks

**What:** Recent performance comparison on 33M rows (Hacker News dataset)  
**Why it's interesting:** Clear guidance on when to use each tool for NHS-scale data work

**Key findings:**
| Operation | Winner | Speedup vs Pandas |
|-----------|--------|-------------------|
| CSV Reading | Polars | 7.7x faster |
| Joins | Polars | 5x faster |
| GroupBy | DuckDB/Polars tie | 4-5x faster |
| Memory Usage | DuckDB | Auto spill-to-disk |

**Recommendation for NHS work:**
- **DuckDB** for SQL-style analysis, memory-constrained environments, large aggregations
- **Polars** for transformation pipelines, CSV processing, lazy evaluation workflows
- **Pandas** for small data, visualization compatibility, quick exploration

**URL:** https://motherduck.com/blog/duckdb-versus-pandas-versus-polars/  
**Benchmark repo:** https://github.com/prrao87/duckdb-study

## 🎯 Apache Superset - Enterprise Power BI Alternative

**What:** Open-source BI platform with 40+ visualization types, SQL Lab, and dashboard builder  
**Why it's interesting:** Apache Foundation project - not going anywhere. Self-hosted, no licensing costs. Supports BigQuery, Snowflake, PostgreSQL, MySQL, Databricks, and more.

**Use case for NHS:** 
- Replace Power BI for internal dashboards
- SQL Lab for ad-hoc queries
- Embeddable charts in internal tools

**URL:** https://superset.apache.org/  
**Demo:** https://superset.apache.org/docs/installation/

**Pros vs Power BI:**
- Free and open source
- SQL-first workflow
- 40+ chart types, plugin architecture for custom viz
- Python/SQL integration

**Cons:**
- Self-hosting required
- Steeper learning curve than Power BI
- No natural language queries (yet)
