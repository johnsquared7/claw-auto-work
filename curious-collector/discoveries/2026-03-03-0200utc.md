## 1. LibreDB Studio — AI-Powered Open-Source SQL IDE

**What:** Browser-based SQL IDE with AI features  
**Why it matters:** Free, self-hosted alternative to DataGrip/DBeaver with AI query generation and optimization built-in

**Key features:**
- **NL2SQL Copilot** — Ask questions in plain English, get executable SQL
- **AI Query Safety** — Pre-execution risk analysis for destructive queries (DELETE, DROP)
- **Visual EXPLAIN** — Graphical execution plans with AI-powered plain-language explanations
- **AI Query Autopilot** — Automated slow query analysis with index recommendations
- **Data Masking** — Auto-detect sensitive columns (email, phone, NHS numbers)
- **7+ databases** — PostgreSQL, MySQL, Oracle, SQL Server, SQLite, MongoDB, Redis

**Use case for NHS:** Could replace paid SQL tools. AI safety features are great for analysts working with sensitive healthcare data — warns before running accidentally destructive queries.

**Verdict:** Worth trying as a free, modern alternative to heavyweight SQL clients.

**Link:** https://libredb.org/

## 2. DataPrep.EDA — Faster Alternative to ydata-profiling

**What:** Low-code Python library for one-line Exploratory Data Analysis  
**Why it matters:** Much faster than ydata-profiling (their claim), with similar output

**Quick comparison:**
```python
# ydata-profiling (original pandas-profiling)
from ydata_profiling import ProfileReport
report = ProfileReport(df)

# DataPrep (potentially faster)
from dataprep.eda import create_report
report = create_report(df)
```

**Use case for NHS:** Quick data quality checks on new NHS datasets. Both generate HTML reports with:
- Column statistics, missing values, distributions
- Correlation analysis
- Interactive visuals

**Verdict:** Good alternative to have in toolkit. Worth testing against ydata-profiling with actual NHS data to see speed difference.

**Link:** https://github.com/sfu-db/dataprep

## 3. Aiven Free SQL Query Optimizer

**What:** Free online SQL optimization tool for PostgreSQL and MySQL  
**Why it matters:** No signup required, free to use, gets you indexing and query rewrite recommendations

**How it works:**
1. Paste your SQL query
2. Select database type (PostgreSQL/MySQL)
3. Get recommendations for indexes and rewrites

**Use case for NHS:** Quick optimization of slow queries without installing additional software.

**Link:** https://aiven.io/tools/sql-query-optimizer
