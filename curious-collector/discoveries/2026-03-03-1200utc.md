### 1. Polars — The Fast Pandas Alternative (REALLY Fast)
**URL:** https://github.com/pola-rs/polars

Polars is a **DataFrame library written in Rust** with Python bindings, and it's significantly faster than pandas.

**Performance benchmarks:**
- **5-10x faster** on group-by operations (parallelized hash-based aggregation)
- **Up to 11x faster** on sorting operations
- **30x speedup** reported by real users on large Excel-like datasets
- LazyFrame execution with query optimization (pandas evaluates eagerly)

```python
import polars as pl

# Simple migration from pandas
import pandas as pd
df_pandas = pd.read_csv("nhs_data.csv")
df_polars = pl.read_csv("nhs_data.csv")

# Polars lazy mode - builds optimized query plan
result = (
    pl.scan_csv("nhs_data.csv")  # lazy
    .filter(pl.col("waiting_list") > 100)
    .group_by("trust")
    .agg(pl.col("patients").sum())
    .collect()  # execute optimized plan
)
```

**Why it's interesting for John:**
- NHS datasets can be large; Polars handles them much faster
- Similar API to pandas (easy migration)
- No dependencies issues (Rust-based)
- Works great with DuckDB for SQL queries

**Relevance:** HIGH — Direct replacement for pandas in John's NHS workflow

### 2. pgBadger — PostgreSQL Query Analyzer
**URL:** https://github.com/darold/pgbadger

Open-source **PostgreSQL log analyzer** that shows exactly what's slow.

- Parses PostgreSQL logs to identify slow queries
- Shows execution time distribution
- Identifies missing indexes
- Generates detailed HTML reports

```bash
# Install
sudo apt-get install pgbadger

# Run against postgres logs
pgbadger /var/log/postgresql/postgresql-*.log -o report.html
```

**Why it's unique:** Free, self-hosted, actively maintained (3.5k GitHub stars). Gives you what expensive tools do but for free.

**Relevance for John:** MEDIUM — If NHS uses PostgreSQL, this is gold
