## 1) Polars — Rust-powered DataFrame library (37k+ GitHub stars)

**URLs**
- https://github.com/pola-rs/polars
- https://pola.rs/

**Why this is genuinely interesting**
- Written in Rust, offers 5-10x speedup over pandas for typical operations.
- Native SQL query engine built-in — can write `pl.sql()` queries directly against DataFrames.
- Better memory efficiency than pandas, especially useful for large NHS datasets.

**NHS workflow angle**
- Direct replacement for pandas in recurring report scripts — same API surface, much faster.
- Can handle larger extracts without running into memory issues on analyst machines.

**Quick pilot**
- Convert one existing pandas-based monthly report to Polars, benchmark runtime difference.

## 3) Apache Superset — Enterprise-grade open source BI (60k+ GitHub stars)

**URLs**
- https://superset.apache.org/
- https://github.com/apache/superset

**Why this is genuinely interesting**
- Cloud-native, scales to enterprise needs (used by Airbnb, Lyft, Netflix).
- SQL IDE built-in, rich visualization library, semantic layer for defined metrics.
- Can connect to Postgres, MySQL, BigQuery, Snowflake, and more.

**NHS workflow angle**
- Free alternative to Power BI — can self-host or use managed version.
- Good for sharing dashboards across analyst teams without per-user licensing costs.

**Quick pilot**
- Spin up Superset locally with Docker, connect to one existing database, build one dashboard.

## 4) xlwings — Python-driven Excel automation

**URLs**
- https://www.xlwings.org/
- https://github.com/xlwings/xlwings

**Why this is genuinely interesting**
- Excel as frontend, Python as backend — live formulas, charts, pivot tables controlled by code.
- Uses Jinja2 templating for complex reports.
- No Excel license needed on the server (runs headless).

**NHS workflow angle**
- NHS still lives in Excel — this bridges Python analysis into familiar formats.
- Better than VBA for maintainable, version-controlled report generation.

**Quick pilot**
- Convert one manual Excel report to xlwings-powered generation with a Jinja template.
