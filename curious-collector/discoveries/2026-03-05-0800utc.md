## 📊 Python + SQL Integration Patterns

**Key insight from research:**

| Use For | Tool |
|---------|------|
| Data transformation in-database | SQLAlchemy Core |
| ORM / app development | SQLAlchemy ORM |
| Large dataset processing | Pandas with chunking + SQLAlchemy |
| Quick analysis | Pandas + raw SQL |

**Best practice (2026):**
- Use `pandas.read_sql()` with SQLAlchemy connection for seamless pipeline
- For large NHS datasets: chunk data with `chunksize` parameter
- Connection pooling via SQLAlchemy handles repeated queries efficiently

**Resources:**
- KDnuggets: Using SQL with Python: SQLAlchemy and Pandas
- DeepNote: Ultimate guide to SQLAlchemy

## ⚡ SQL Optimization Tools (2026)

**Key tools identified:**
- **EXPLAIN / EXPLAIN ANALYZE** — universal, supported by most DBs
- **PawSQL** — intelligent query optimization for MySQL/PostgreSQL
- **Releem** — AI-powered MySQL performance monitoring
- **Cloud-native**: BigQuery partitions, Snowflake result caching, Databricks Delta Lake

**For NHS data (typically MSSQL/PostgreSQL):**
- Indexing is critical for large patient datasets
- CTEs (Common Table Expressions) improve readability and performance
- Avoid SELECT * — explicitly name columns

## 🤖 Report Automation Patterns

**Stack:**
- **pandas** + **openpyxl** for Excel generation
- **matplotlib** / **Plotly** for charts in PDFs
- **Quart/Flask** + **WeasyPrint** for HTML-to-PDF
- **APScheduler** or **cron** for scheduling
- **smtplib** / **yagmail** for email

**Useful repos:**
- `Bwhiz/Auto-Excel-Reports` — GitHub Actions + openpyxl + scheduled email

**Pattern for NHS weekly reports:**
1. Query SQL → pandas DataFrame
2. Generate Excel with multiple sheets (summary + detail)
3. Add charts with openpyxl or xlsxwriter
4. Schedule with cron + email via SMTP
