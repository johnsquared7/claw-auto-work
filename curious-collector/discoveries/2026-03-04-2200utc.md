## 🐍 Python Data Analysis

### Vaex — Out-of-Core DataFrames for Large NHS Datasets
- **What:** Lazy evaluation + memory mapping; handles billions of rows on a laptop
- **Why relevant:** NHS datasets can be huge; Vaex won't choke RAM
- **URL:** https://vaex.io/
- **Key feature:** pandas-like API but scales beyond memory

### Pandera — Data Validation for pandas
- **What:** Schema validation bring type-hinting to DataFrames
- **Why relevant:** Validates NHS data quality at pipeline runtime
- **URL:** https://pandera.readthedocs.io/
- **Key feature:** Informative error messages when validation fails

### cuAccelerated DataFramesDF — GPU-
- **What:** NVIDIAIDS library; RAP pandas-like API but runs on GPU
- **Why relevant:** 50-100x speedups for groupby, join, filter operations
- **URL:** https://docs.rapids.ai/api/cudf/stable/
- **Note:** Requires CUDA-capable GPU; check NHS machine specs first

### Sweetviz — Automated EDA in Seconds
- **What:** One-line EDA reports with target analysis
- **Why relevant:** Fast dataset comparison (train/test, before/after)
- **URL:** https://github.com/fbdesignpro/sweetviz

### ITables — Interactive DataFrames in Jupyter
- **What:** Search, sort, paginate DataFrames in notebooks
- **Why relevant:** Handles large DataFrames efficiently; renders only visible rows
- **URL:** https://pypi.org/project/itables/

## ⚡ SQL Optimization

### EverSQL — AI-Powered SQL Optimizer
- **What:** PostgreSQL & MySQL optimizer; 100k+ engineers use it
- **Why relevant:** Paste query → get optimized version with explanations
- **URL:** https://www.eversql.com/
- **Tiers:** Free tier available; paid for ongoing monitoring

### SQLAI.ai — Free SQL Optimizer
- **What:** LLM-powered query optimization
- **Why relevant:** Free, no signup required for basic use
- **URL:** https://www.sqlai.ai/sql-optimizer
- **Note:** Good for quick query improvements

### Explo AI SQL Optimizer
- **What:** First-pass SQL improvement via LLMs
- **Why relevant:** Simple workflow: paste → optimize → copy
- **URL:** https://www.explo.co/sql-tools/ai-sql-optimizer
