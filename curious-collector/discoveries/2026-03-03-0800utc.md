## 🎯 Key Findings

### 1. Evidence.dev — BI as Code
**URL:** https://evidence.dev/

A unique approach to BI: build reports using **SQL + Markdown**. It renders a static website from markdown files containing SQL queries.

- Write queries in markdown, get interactive charts
- Version control your reports like code
- Supports PostgreSQL, MySQL, SQLite, Snowflake, BigQuery
- Perfect for analysts who prefer code over drag-and-drop

**Why it's unique:** Unlike Metabase/Superset, this is **headless BI** — you write markdown, get a website. No GUI needed.

**Relevance for John:** High — fits Python/SQL workflow, great for automated NHS reports

### 2. Great Expectations (GX Core) — Data Quality
**URL:** https://greatexpectations.io/gx-core/

Open-source Python framework for validating data quality. Think of it as **unit tests for data**.

- Define "expectations" for your data (e.g., "column X must not be null", "values in column Y must be between 0-100")
- Automatically validate datasets
- Generate data docs with validation results
- Integrates with pandas, SQLAlchemy, Spark

**Why it's relevant for NHS:** Data quality is critical in healthcare. Validate that:
- Patient IDs are valid formats
- Dates are within expected ranges
- No duplicate records
- Cross-field validation (e.g., discharge date > admission date)

**Relevance for John:** High — essential for NHS data pipelines

---

### 3. Altair — Declarative Visualization
**URL:** https://altair-viz.github.io/

Not new, but often overlooked. Altair is a **declarative** Python visualization library based on Vega-Lite.

```python
import altair as alt
alt.Chart(df).mark_bar().encode(
    x='column1',
    y='count()',
    color='category'
).interactive()
```

- Concise, readable code
- Built-in interactivity (hover, zoom, pan)
- Handles data transformations natively
- Great alternative to matplotlib/seaborn for quick EDA

**Relevance for John:** Medium — nice for quick data exploration
