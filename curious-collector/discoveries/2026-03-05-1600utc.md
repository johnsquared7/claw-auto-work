## 🔥 Polars - The Fast Pandas Alternative

**What:** High-performance DataFrame library written in Rust  
**Why it's interesting:** Claims 10x faster than Pandas on many operations, lazy evaluation, better memory efficiency  
**Use case for NHS:** Large dataset processing for waiting list analytics, elective care data  
**URL:** https://pola.rs/

## 🦆 DuckDB - SQL on Files

**URL:** https://duckdb.org/
