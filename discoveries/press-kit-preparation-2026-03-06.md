# Press Kit Preparation for Home Screen Organizer Launch

**Research Date:** 2026-03-06
**Researcher:** Oracle

---

## Essential Press Kit Components

### 1. App Description Materials
- **App name & tagline** (under 100 characters for headline)
- **Short description** (1-2 sentences, 50-100 words)
- **Long description** (3-5 paragraphs covering features, use cases, target audience)
- **Key features list** (bullet points, max 5-7)
- **Unique value proposition** (what makes it different)

### 2. Visual Assets
- **App icon** (1024x1024 PNG with transparency)
- **Screenshots** (6.5" iPhone screenshots, portrait + landscape if applicable)
  - Minimum: 3-5 screenshots showing key features
  - Include before/after home screen transformation
- **App preview video** (15-30 seconds, show aha moment)
- **Logo variations** (light/dark backgrounds, horizontal/vertical)
- **Founder/team photos** (high-res, professional)
- **Lifestyle imagery** (app in use context)

### 3. Press Release
- **Headline** (action verb + benefit, under 100 characters)
- **Dateline** (city, state, date)
- **Opening paragraph** (who, what, when, where, why)
- **Body paragraphs** (features, benefits, pricing, availability)
- **Founder quote** (mission-driven, authentic)
- **About section** (company background, 3-5 sentences)
- **Media contact** (name, email, phone, website, press kit URL)
- **Boilerplate** (### marks end)

### 4. Fact Sheet
- App name & category
- Launch date & platforms
- Pricing model (free/freemium/premium)
- Key features (bullet list)
- Target audience
- Company info
- Download links

## Timing Strategy

### Press Release Distribution
- **Send 10-12 days before** App Store availability
- **Best days:** Tuesday-Thursday
- **Best time:** 10 AM - 2 PM in target journalist's timezone
- **Avoid:** Fridays, weekends, major holidays

### Embargo Strategy
1. **Embargoed outreach** to select reporters (5-7 days before launch)
2. **Broader distribution** on announcement day
3. **Owned channel promotion** (social, email, blog) synchronized with press

## Press Kit Hosting Options

1. **Dedicated page** on company website (`/press`)
2. **Google Drive folder** (organized, shareable link)
3. **Press kit service** (ImpressKit, PressRoom)

## Pre-Launch Checklist

- [ ] Finalize app name, tagline, description
- [ ] Prepare 5-7 high-quality screenshots
- [ ] Create 15-30 second preview video
- [ ] Write press release (get founder quote)
- [ ] Build press kit page/folder
- [ ] Identify 10-15 target journalists
- [ ] Draft personalized pitches
- [ ] Schedule embargoed outreach (10-12 days before)
- [ ] Plan synchronized announcement across channels
- [ ] Prepare social media assets (Twitter, LinkedIn, Instagram)

---

## Key Takeaways

1. **Start early** - Press kit should be ready 2+ weeks before launch
2. **Lead with value** - Focus on user benefit, not features
3. **Make it easy** - Journalists need all assets in one place
4. **Build relationships** - Engage with journalists before pitching
5. **Time strategically** - Tuesday-Thursday mid-morning for distribution
6. **Coordinate channels** - Press, Product Hunt, social, email all synchronized
