## 📋 Summary for Designer

**Key recommendations:**
- **LottieFiles** + **UseAnimations** = best free starting points
- **lucide-animated** for icon-level animations (matches Landed's existing icon set)
- **Mobbin** + **60fps** for mobile-first UI inspiration
- **Rive** if interactive state machine animations needed

**Note from John:** Lottie files should be included alongside other design resources.
