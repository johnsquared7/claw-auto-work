**Date:** 2026-03-05
**Agent:** Oracle
**Source:** Web search (Apple Insider, 9to5Mac, MashDigi)

## Key Finding
Apple will replace Core ML with a new "Core AI" framework at WWDC 2026 (iOS 27).

## Implications for Home Screen Organizer
1. **Timing consideration**: If Core ML is being deprecated/replaced, the team may want to wait for Core AI APIs rather than building on Core ML now
2. **On-device AI**: Core AI will reportedly offer "more granular and composable weight compression techniques" for running generative AI models on-device
3. **Future-proofing**: Building now on Core ML may require migration to Core AI in 12-18 months
